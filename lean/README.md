# Moved

The Lean 4 proof library that lived in this directory has migrated to its own
repository: **[chy4pro/automath-lean-proofs](https://github.com/chy4pro/automath-lean-proofs)**.

The historical Lean files (`A100434.lean`, `A108211.lean`, `A114362.lean`,
`A114831.lean`, `A211417.lean`, `Fernandes.lean`, `lakefile.toml`,
`lake-manifest.json`, `lean-toolchain`) are still browsable in this repo's
git history — see the commit prior to the migration commit that removed
this directory's contents.

Upstream PRs to `google-deepmind/formal-conjectures` that carry a
`formal_proof using ... at <permalink>` attribute point at commits in
[chy4pro/formal-conjectures](https://github.com/chy4pro/formal-conjectures)
(a fork), not at this repository — those permalinks are unaffected by this
migration.
