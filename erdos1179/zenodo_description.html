Let G be any finite abelian group of order N, and put q = log2N and L = log2q. For a sample A of size k, let RA(g) count subset sums, including the empty subset. We require |NRA(g)/2k − 1| ≤ 1/2 simultaneously for every g. Model (I) uses independent uniform entries, with repeated entries retaining distinct indices; model (U) uses a uniform k-element subset.

Main theorem. If N ≥ 264, every integer k ≥ q + 8400√(qL) has failure probability at most 1/(2q) in model (I). If also k ≤ 2q/2, the failure probability is at most 1/q in model (U). For N ≥ 2486018750, the constant is 200, with the same probabilities and the same additional upper bound on k in model (U). Both subset intervals are nonempty. All constants and onsets are explicit, and q is real.

The paper also proves both probability bounds for k = ⌈q + 1000q/log2q⌉ when N ≥ 2220, and for k = ⌈q + 3400q4/5⌉ when N ≥ 264. A corollary gives k = ⌈q + 3q4/5⌉ when N ≥ 2486018750. These fixed sizes satisfy k ≤ N. The proof splits a Fourier power by integer relation lattices, uses a deterministic bound on a common event for the low-rank part, and takes an unconditional second moment of the remaining polynomial. A sharper count of bounded-generator lattices yields the correction of order √(q log q).

Finite-size scope. The elementary L2 estimate already suffices for k ≥ 2q + L + 3. At the minimal allowed sizes, the respective guaranteed comparison ranges are q ≥ 21000 for the 1000q/log2q bound, q ≥ 34005 for the 3400q4/5 bound, and q/L ≥ 84002 for the main bound with constant 8400. The main bound with constant 200 improves the elementary size throughout its stated range. The paper treats the ceilings explicitly and does not claim that these sufficient comparison ranges are the exact rounded crossover points. Constants are not optimized.

Literature. The leading-coefficient-one question in Erdős Problem #1179 was already settled by Erdős–Hall (1976). Within a literature search of 12 October 2026 we did not locate an explicit bound of this form for all finite abelian groups. This is a bounded search statement, with no priority claim: Hall (1977) remained unread, and forward-citation coverage was incomplete. The paper discusses the explicit Erdős–Rényi theorem and stronger restricted finite-field results of Dhar–Dvir and Lund, Two-sided linear hashing and quadratic density bounds for smooth lattice coverings, arXiv:2609.20351v1. Those finite-field statements do not supply a uniform theorem for every finite abelian group.
