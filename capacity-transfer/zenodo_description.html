This note proves explicit second-order bounds for sonar sequences, weak Sidon sets and related distinct-difference configurations using a signed interval-capacity certificate with boundary constant 2/3.

The main result is that every sonar sequence with n rows, one point in each of m columns, and distinct nonzero ordered displacement vectors satisfies

m ≤ n + 3(π²/36)1/3 n2/3 + 4n1/3, for every integer n ≥ 160³.

The argument preserves the exact column marginal in the Cauchy–Schwarz inequality. The note gives a self-contained proof of the signed capacity certificate and includes the following further results:

  • The triangular-kernel sonar bound m ≤ n + 2n2/3 + 3n1/3, for n ≥ 48³.
  • For weak Sidon subsets of an interval of N integers, with diagonal sums excluded, |A| < √N + √(8/3)N1/4 + 2, for every integer N ≥ 90⁴.
  • For integers g,N ≥ 1 and A ⊆ {0,…,N−1} with at most g representations of every nonzero ordered difference, |A| < √(gN) + (2√2/3)(gN)1/4 + 1, provided gN ≥ 120⁴. This is a routine rescaling of the scalar Sidon inequality.
  • For n rows of k+1 increasing integer marks, each row starting at zero, with globally distinct positive within-row differences, the minimum scope (the largest mark) exceeds n[(√(4k+8/9)−2√2/3)/2]⁴, for all integers n ≥ 1 and k ≥ 20365. An expanded bound with an explicit remainder is also proved.
  • For finite square-grid configurations with distinct nonzero ordered difference vectors and Manhattan diameter at most r, |A| ≤ r/√2 + (4/3)1/3r2/3 + 9r1/3, for every real r ≥ 160³.
  • For strong Sidon sets in {0,…,N−1}d, including diagonal sums, |A| ≤ Nd/2 + cdNd²/(2d+2) + 2d²Nd(d−1)/(2d+2), where cd = ((d+1)/2)(8/9)d/(d+1), for integers d ≥ 2,N ≥ 1 with Nd/(2d+2) ≥ max(120,4d). In dimension two, |A| ≤ N + (8/3)1/3N2/3 + 18N1/3 holds for every integer N ≥ 1.

The kernel functional f(0)∫|t|f(t)dt has attained optimum π²/32 among autocorrelations of nonnegative unit-mass factors. An explicit continuous, nonnegative positive-definite perturbation gives a strictly smaller value in the full admissible class. The exact infimum over that larger class remains open. No optimality is claimed for arbitrary two-dimensional kernels or all combinatorial methods.
